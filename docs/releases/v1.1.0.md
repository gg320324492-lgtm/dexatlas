# v1.1.0 — Q2 桌面应用与稳定性批次

**日期：** 2026-11-25 · **tag：** `v1.1.0` · **上一版本：** [v1.0.2](v1.0.2.md)（2026-11-24）

v1.1.0 交付 Phase 4 Q2 补充单授权的**原创桌面应用**（Tauri 2 + React 19 +
TypeScript，与既有 CLI/REST/MCP/Workbench 并存），以及 Q2 后稳定性批次的全部
修复。自 v1.0.2 起 main 共 41 个提交，经 9 个 PR 逐一评审合并。

## What's new

### 桌面应用 DexAtlas Studio

- **设计规范先行**：信息架构、视觉 token（深海军蓝 + 淡紫/橙渐变、16px 圆角、
  两级阴影、渐变仅首屏）、19 组件清单、状态矩阵、键盘行为，见
  [desktop-app.md](../architecture/desktop-app.md)。
- **组件库与画廊**：21 个基础组件 + 组件画廊页（`/#/gallery`），所有页面只从
  组件库取用。
- **核心工作流接真实数据**：首页拖拽上传（`POST /api/analyze`，.apk 校验、
  超大文件与同 hash 提示）→ 分析进行中页（阶段进度由 runs 状态驱动、状态
  时间线、后端健康）→ 项目详情三栏 + 证据抽屉（真实 locator、resolve 动作）
  → 报告导出（Markdown/JSON 下载）→ 证据检索 → 设置。
- **可分发产物**：`npx tauri build` 产出自包含 release exe 与 MSI/NSIS 安装包；
  发布形态经真机验证（CORS 对比实测、首页/详情/导出全链路）。
- **性能基线**：九项真机测量全部达标（冷启动 892ms、路由最慢 82ms、证据渲染
  64ms、导出 56–78ms、轮询 CPU 0.06%、内存稳定、缩放无破版），见
  [phase4-q2-perf-walkthrough.md](../reports/phase4-q2-perf-walkthrough.md)。
- **验收**：按 Q2 补充单 §6 八维度逐项通过，截图与证据见
  [phase4-q2-acceptance.md](../reports/phase4-q2-acceptance.md)。

### workbench 后端补齐（桌面端依赖）

- `GET /api/backends`、`GET /api/projects/{id}/runs`、
  `GET /api/projects/{id}/runs/{run_id}`、`POST /api/projects/{id}/cancel`
  （202/409），复用 MCP 契约形状；9 例回归测试先红后绿。
- **孤儿 run 对账**：workbench 启动时把死进程遗留的 `running` run/项目如实
  改写为 `failed` 并记录原因（本机 strings.apk 自 11-23 起僵尸 running 的根因）；
  跳过本进程活着的分析，幂等；2 例新回归测试。

### 桌面端稳定性与可访问性

- 分析页轮询指数退避重试 + 手动刷新；首页项目列表骨架屏；上传边界提示；
  错误文案统一（`describeError`，去掉 `undefined:` 前缀）。
- 核心链路 skip-link（验收 A-7）；日志长 token 断行修复；1920 宽屏内容
  max-width 居中；导出按钮文案统一。

## Verification

- 套件：**1819** 个测试（1670 快 + 149 集成），**1818 passed, 1 skipped,
  0 xfailed**，覆盖率 **93.3%**（7375/7904 行），由
  `scripts/refresh-report-figures.py` 对发布树完整测量生成（后端环境变量、
  fixtures、Pillow、ffmpeg 齐备，无 skip 掩盖）。
- 门禁：ruff lint + format、mypy strict、vulture、check-doc-citations、
  check-version-claims、check-release-numbers、make-social-preview 全部通过。
- 桌面应用：`npm run build` 零错误；Tauri release 真机全链路实测（上传 →
  证据 → 导出）。

## What this release does not claim

- 桌面应用第一验收平台是 Windows；macOS/Linux 未验证。
- 分析页的阶段级进度中，后端无阶段级进度接口的粒度部分为前端模拟，UI 有
  常驻角标如实标注；实时日志流后端未提供，展示的是状态轮询记录。
- 未做应用商店分发、自动更新服务与签名证书；安装包仅为本机构建产物。
- 桌面应用通过本地 HTTP 调用既有分析核心，不引入新的分析能力。
