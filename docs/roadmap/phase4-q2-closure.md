# Phase 4 Q2 收尾单 — 桌面应用阶段的结束条件

**日期：** 2026-11-24 · **性质：** Q2 收尾执行单 · **状态：** 待 Q2-M1–M3 完成后回填

## 1. 收尾目标

Q2 桌面应用阶段结束时，项目必须能回答三个问题：

1. 桌面应用是不是做出来了，能不能在 Windows 上启动？
2. 它有没有守住 DexAtlas 的公共契约和证据优先原则？
3. 下一个阶段的冻结/解冻范围是什么？

本单是 Q2 的**退出门禁**：没有逐项回填之前，Q2 不能宣布完成。

## 3. 退出条件（全部满足才可收尾）

### 3.1 产品与设计

- [ ] 首屏呈现"拖拽上传 + 最近项目"，气质为高端浅色工作室。
- [ ] 深海军蓝主色 + 淡紫/橙渐变仅用于既定区域；圆角、阴影、渐变 token 生效。
- [ ] 线性图标风格统一；首屏插画不复制第三方版权资产。
- [ ] 左侧栏导航覆盖项目/分析/证据/报告/设置。
- [ ] 分析页呈现阶段进度、实时日志、后端状态三区。
- [ ] 详情页为列表/主体/证据抽屉三栏结构。
- [ ] 版本号、构建号、后端版本细节不出现在首屏常驻区域。

### 3.2 功能与证据链

- [ ] 用真实 `examples/demo-app/demo.apk` 完成"拖入 APK → 查看证据 → 导出报告"。
- [ ] 证据条目能展示来源工具、版本与 locator，并能触发解析动作。
- [ ] 分析失败/部分成功时，界面如实呈现，不把失败包装成完成。
- [ ] Agent/模型入口在未配置时明确拒答，不使用替身回答。

### 3.3 工程与契约

- [ ] Tauri + React + TypeScript 工程可在 Windows 本地构建并启动。
- [ ] 桌面应用通过本地进程/HTTP 调用现有 DexAtlas 能力，不复制分析逻辑。
- [ ] 现有 pytest、ruff、mypy、vulture、check-doc-citations、check-version-claims、check-release-numbers、make-social-preview 全部通过。
- [ ] REST、MCP、CLI、报告 schema、证据 locator、状态码、退出码无破坏性变更。
- [ ] 新增代码不把第三方 APK、DEX、so 或秘密带入仓库。

### 3.4 可访问性与细节

- [ ] 核心链路全程键盘可达，焦点可见。
- [ ] loading / empty / error / partial 四类状态有统一组件呈现。
- [ ] 拖拽上传有文件类型校验与错误反馈。
- [ ] 动画尊重 `prefers-reduced-motion`，不做无意义动效。

### 3.5 文档与发布

- [ ] `docs/status.md` 更新 Q2 状态与新的冻结/解冻边界。
- [ ] `docs/roadmap/ROADMAP.md` 登记 Q2 阶段。
- [ ] 报告索引收录 Q2 验收报告。
- [ ] 如需对外发布，版本号、CHANGELOG、release notes、social preview 按既有脚本流程更新，不手改生成数字。

## 4. 验收流程

1. **自检：** 按 §3 清单逐项勾选，附文件路径或截图。
2. **真实运行：** 在 Windows 上启动 Tauri 原型，用 demo APK 走完整链路。
3. **截图对照：** 按"定义产品方向 / 搭建信息结构 / 控制视觉语言 / 按标准迭代"四步，分别截图说明达标点。
4. **门禁复跑：** 运行 CLAUDE.md 规定的本地门禁，输出贴进验收报告。
5. **状态回填：** 更新 status、ROADMAP、报告索引与本单的状态列。
6. **再次定界：** 明确 Q2 之后是继续解冻、部分解冻还是重新冻结。

## 5. 下一阶段定界（初稿）

Q2 收尾时必须从以下三选一，并写进 status：

- **A. 继续解冻：** 桌面应用进入功能扩展（更多分析视图、更深的 agent 集成等）。
- **B. 部分解冻：** 只允许修桌面应用的缺陷、性能与可用性问题；新功能重新评审。
- **C. 重新冻结：** 桌面应用达到可展示水平后，回到"真实用户信号驱动"的冻结状态。

默认建议：**B. 部分解冻**——桌面应用刚落地，先以稳定性和真实使用反馈为主，不急于扩展新功能面。

## 6. 最终决策记录

- Q2 是 Phase 4 之后的**追加阶段**，不改变 M11–M15 已完成事实。
- 冻结解除仅限桌面应用范围；主分析核心契约继续受保护。
- 收尾以**可运行原型 + 真实数据链路 + 截图对照 + 门禁全绿**为准，不以"代码看起来完成"为准。
